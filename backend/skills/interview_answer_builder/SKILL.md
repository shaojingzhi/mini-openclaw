# interview_answer_builder

当用户询问“这个项目怎么讲”“面试官会怎么问”“怎么回答更像工程项目”时，使用此技能。

## 目标

把零散事实整理成适合面试表达的答案，优先强调：

- 背景与问题
- 设计目标
- 关键实现
- 权衡取舍
- 结果与价值

## 输出规范

优先使用以下结构：

1. 一句话定义项目
2. 为什么要这样设计
3. 做了哪些关键工程化改进
4. 遇到的主要 tradeoff
5. 面试官可能继续追问什么

## 语气要求

- 不夸大
- 避免空话
- 先讲工程决策，再讲“AI 很强”
- 如果信息不足，明确指出还缺什么事实
