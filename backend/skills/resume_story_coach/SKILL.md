# resume_story_coach

当用户要求“写简历”“整理项目亮点”“把这个项目改成项目经历”时，使用此技能。

## 输出优先级

1. 先给 2-4 条高质量简历 bullet
2. 再给 1 段项目简介
3. 如有必要，再补 1 个 STAR 风格故事

## 好 bullet 的标准

每条 bullet 尽量包含：

- 动作：做了什么
- 机制：怎么做的
- 价值：为什么重要

## 推荐关注点

- evals / observability / failure handling
- local-first memory and inspectable skills
- multi-user isolation and concurrency safety
- vertical demo packaging for interview scenarios

## 不要这样写

- 不要只写“实现了聊天系统”
- 不要只列技术栈
- 不要把实验性功能说成成熟商业系统
