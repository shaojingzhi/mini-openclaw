# Interview Question Bank

## System design and architecture

1. Why did you choose FastAPI + Next.js for this agent workspace?
2. What tradeoffs did you make by keeping memory file-based?
3. How would you evolve this from local single-user to hosted multi-user?
4. Why does traceability matter in agent products?
5. What parts of the system are easiest to test, and which are hardest?

## Agent-specific reasoning

1. How do skills differ from plain prompting?
2. Why can tool-call observability matter more than raw model quality?
3. When should an agent retry versus fail fast?
4. How do you avoid hidden state causing confusing behavior?
5. What failure mode is most dangerous in an agent product demo?

## Behavioral / project storytelling

1. What was the highest-leverage improvement you made to Mini-OpenClaw?
2. Describe a bug or architectural issue you found and fixed.
3. How did you make the project more convincing to an interviewer?
4. What did you choose not to build, and why?
5. What would you do next with one more week?

## Suggested answer style

- start with the product goal
- mention the engineering constraint
- explain the design choice
- call out the tradeoff
- end with what this unlocked next
